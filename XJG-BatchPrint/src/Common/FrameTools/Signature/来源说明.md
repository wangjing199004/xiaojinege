从 `F:\Codedemo\Tk\Source\Core` 的 5.26.0 源码复制，并引入原 `Source\Single\GreenStore.cs` 与 `GreenArchive.cs` 的加密缓存机制。

保留原绘图、标定、人员编辑、配置包及签名库实现，原项目未修改。

集成改动：

- `Commands` 改为 partial，通过 `Commands.Integration.cs` 将原私有业务动作提供给新的停靠标签页，不使用原模态主菜单循环。

- `Import-SignatureData.ps1` 仅复制原加密缓存、配置包、标定与加密素材库，不覆盖新版已有设置。运行时重定向素材目录到新版会话目录，避免回写原项目。

没有引入原 Loader 或 SingleCommands，不重复注册 TKQM / CADSIGN 等命令。使用现有 `TKATTR` 命令打开统一面板。
