# 批量打印插件 v1.15.7.2 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。修复多文件批打预览报错，并让 CTB 编辑跟随 CAD 当前的打印样式搜索路径。

## 多文件批打

- 非当前打开的 DWG 改为打开并切到活动文档后再出图，不再走侧库出图（避免图号对、页面全白）。
- 点列表「预览」时，先在应用上下文打开并激活源 DWG，再投递文档命令启动 PlotEngine；预览结束后切回原图，仅关闭本次临时打开的文件。
- 当前打开图的预览、单张框选和 `PlotDatabase` 行为不变。

## 打印样式（CTB）

- 下拉列表仍使用 CAD 自己的打印样式表名单，打印不受影响。
- 点「设置」编辑 CTB 时，按选项中的打印样式表搜索路径（`PrinterStyleSheetPath` / `STYLESMANAGER` 同一套目录）定位文件，不再拼默认 `Plotters` 目录。
- 用户改过默认 CTB 目录后，编辑与打印使用同一份文件；找不到或无法关联编辑器时，打开 CAD 的 `STYLESMANAGER`。
