# 批量打印插件 v1.15.7.1 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。在 v1.15.7 基础上，完善通用型矩形框的属性命名、纸张识别与改纸，以及识别进度提示。

## 通用型矩形框：属性图号 / 图名

- 扫描时识别顶层块属性 Tag 为「图号」「图名」的非空值（同框取离右下角最近）。
- 本批至少一张识别到属性时，列表显示图号/图名列，文件名按设置中的命名规则生成。
- 混批中无属性的图框回退为 DWG 名 + 序号，避免出现空文件名。

## 纸张识别与改纸

- 短边毫米匹配比例库；失败则按长宽比命中图幅并反推任意比例（不再二次贴库）。
- 任意比例路径下展开 A0～A4 候选，可在下拉中改选其他标准图幅并自动换算比例。
- 批量改纸在候选不一致时，也可按同一套长宽比图幅名统一更换。

## 识别进度

- 扫描当前图 / 框选扫描时弹出可取消的识别进度窗，显示阶段与处理数量。
