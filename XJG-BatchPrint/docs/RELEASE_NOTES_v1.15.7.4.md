# 批量打印插件 v1.15.7.4 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。面板「框选扫描」改为按对象选择识别（点选/框选允许类型的实体），选择阶段按类型过滤并只扫描选中 ObjectId。「扫描当前图」与「框选扫描」共用 `ScanCandidateFilter` 先过滤合适对象再识别；范围对话框保留。

## 框选扫描（对象选择）

- 图框块面板与通用型面板的「框选扫描」改为 GetSelection 选对象，不再使用几何窗口 GetPoint/GetCorner。
- 选择阶段即过滤类型：图框块只允许块参照；通用型允许块参照与各类多段线，开启四线识别时还包括直线。
- 只扫描选中 ObjectId；取消选择时现有清单不变。
- 「扫描当前图」范围对话框保留；范围内同样先按公共类型过滤再识别。

## 框选扫描右键

- 尚未左键拾取时右键：在光标处弹出紧凑扫描范围菜单。
  - 模型空间：当前模型 / 所有布局 / 模型+布局
  - 布局空间：模型空间 / 所有布局 / 模型+布局 / 当前布局名
- 已经左键点选或拉框后右键：确认当前选择（等价回车）。
- 命令入口仍是先打开面板，不强制先选对象。
