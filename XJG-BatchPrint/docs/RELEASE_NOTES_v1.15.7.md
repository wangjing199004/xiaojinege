# 批量打印插件 v1.15.7 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。在 v1.15.6.4 基础上，重点完善批打进度展示、图中交互体验、扫描识别，以及 PNG/JPG 输出。

## 批量打印进度

- 新增置顶进度窗：进度条、当前/总数、当前图纸说明，以及停止按钮。
- 批打期间继续抑制 CAD 引擎进度框，避免盖住插件界面。

## 设置与图中交互

- 修复批打宿主下「比例设置 → 从图中拾取」无响应的问题。
- 目录行高/列宽/点选文字、比例拾取成功后不再弹出成功提示框。
- 比例拾取后不再自动重扫，需新比例时由用户手动扫描。
- 新增图框字段框选改为透明让出 CAD，减轻图面闪烁。

## 扫描与识别

- 四线矩形端点容差按边长 0.1%（下限 0.01）放宽，默认开启四线识别。
- 支持天正单行/多行文字（`TCH_TEXT` / `TCH_MTEXT`）读取图号图名。
- 新增图框允许点选锁定图层上的块。

## PNG/JPG 输出

- PNG/JPG 改为先用 PDF 绘图仪出临时 PDF，再按可配置 DPI 转成图片；文件名规则不变。
- 留白、文字转图形与 PDF 一致。
- 常规设置增加「转图分辨率(DPI)」，默认 150，范围 72–600。
