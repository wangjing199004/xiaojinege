# 出图中心与热更新（v28）

主面板名称为“出图中心”。一级标签页依次为：属性图框、图框签名、图框块打印、通用批量、单张打印、图框库、设置。属性图框与图框签名共用操作忙状态，切换页面保留编辑和文件列表。CAD下拉菜单最前面为属性图框、图框签名，之后用横线与打印功能隔开。原图框库、单张打印、设置及快捷键命令继续跳转到相应页面。

图框工具源码从 F:\Codedemo\属性图框批量修改 的当前版本复制并适配到 src/Common/FrameTools，包含属性批量修改、未打开DWG更新、文件备份、人员设置、签名、标定、封面、图框编号。原项目未修改。所有绘图区选择由普通文档命令调度；图纸关闭或操作取消后释放忙状态。

## 首次使用

从 bin-update-v28 选择对应平台目录，完整保留配套文件。从v25升级到v26时，因新增TKATITLE一键图名命令，需要关闭CAD、更新完整平台目录后重新启动并加载新版Loader；不能仅替换Runtime。首次从更旧版本升级也需要重启，避免旧版已注册的同名命令冲突。NETLOAD只加载下面的加载器：

| 平台 | NETLOAD 加载 | 同目录业务文件 |
| --- | --- | --- |
| AutoCAD 2015–2024 目标 | AcadBatchPlot.Loader.dll | AcadBatchPlot.Runtime.dll |
| AutoCAD 2025–2027 目标 | AcadBatchPlot.Core.Loader.dll | AcadBatchPlot.Core.Runtime.dll |
| ZWCAD 2025 目标 | BatchPlotter.Loader.dll | BatchPlotter.Runtime.dll |

输入 ZBP_SHOW_PANEL 打开面板，或 TKATTR 打开属性图框、TKASIGN 打开图框签名。不要NETLOAD业务Runtime DLL。自动加载菜单现在注册固定加载器路径。上述年份为编译目标，不代表每个版本都已实测。

## 后续热更新

开发时运行：

```powershell
.\scripts\build-hot-update.ps1
# 只编译一个平台；可指定已有插件根目录（根目录下包含三个平台子文件夹）。
.\scripts\build-hot-update.ps1 -Platform Acad -OutputDirectory 'F:\我的插件'
```

保持原加载器和配套文件在安装目录中，替换相应 Runtime.dll 后，在CAD输入 ZBP_RELOAD，或点击设置页底部的“热更新插件”（位于“恢复默认”左侧）。TKARELOAD作为兼容命令也可使用。

热更新重建主窗口，扫描清单、未保存属性编辑和待处理文件列表需要重新加载。已保存的打印设置、图框库、人员设置和标定保留。文件未改变时不重建窗口。正在打印、预览或等待/执行图纸选择时拒绝更新；请完成当前操作或Esc取消后重试。

业务DLL以字节加载，不占用其文件；每次构建使用不同程序集标识，隔离WPF资源缓存。更新失败时尽量恢复上一版；损坏文件在关闭原版前被拒绝。固定加载器、托管依赖或原生库发生变化时仍需重启CAD。运行多次热更新会保留已加载的旧程序集直到退出CAD。

旧 build-dll.ps1 仍用于普通单DLL开发构建；需要热更新时使用 build-hot-update.ps1。旧发行打包脚本并不生成当前热更新交付目录，分发v28时直接复制完整平台目录。

## 签名配置

已把另一个项目的 SignatureData 和人员设置.cspkg复制为当前项目的独立种子；保留原缓存和密钥、图幅标定及加密笔迹库。运行签名时在当前插件目录的 SignatureData/.session临时解密，结束后重新加密并清理工作目录。

首次构建复制配置种子，后续热更新构建不覆盖安装目录已有的 SignatureData 或人员设置.cspkg。移动插件时一同保留这些文件；不要只复制DLL，也不要单独替换已有缓存的密钥。模板加密内嵌方式保持不变。

## 验证范围

三个平台分别编译；配置包、真实签名数据迁移、文件原子保存/备份、独立封面标定和输入调度有回归测试。WPF测试使用两个字节加载的不同业务程序集，检查BAML、嵌套控件和ViewModel归属，防止加载旧界面。

AutoCAD2024控制台用于验证业务DLL加载/替换、忙状态阻止更新、属性TAG写入和锁定跳过、异常更新保护。控制台不支持完整桌面面板，完整Tab显示、按钮交互、签名落点与实际打印需在桌面CAD验收。

## 一键图名与新版模板（v28）

属性图框页第一排为：读取样板图框、框选写入图框、应用当前全图、全选字段、取消全选、一键图名。
点击“一键图名”或输入 TKATITLE，先点选单行文字、多行文字或块内文字，再选择目标属性图框，只改属性标记为“图名”的内容。可连续执行下一对选择，Esc结束；在第二次选择时取消不会写入。
多行源文字去除显示格式，写入单行属性时将换行转为空格；多行属性保留换行。缺少“图名”属性、目标图框/属性图层锁定时提示并不写入，不会改图号等其他字段。可用CAD撤销。
设置 → 快捷键新增“一键图名”，原始命令为TKATITLE；可自定义简化命令，保存后按提示重载PGP或重启CAD。

A0+、A1+、A2+模板已经按“目录”文件夹的最新DWG重新加密并内嵌。A2的模型空间样板参照尚未同步新增图名字段，插入时在临时数据库自动补齐，源DWG不变。三种新图框插入后均有11个空白属性，其中包括图名。
A0、A1、A2已使用最新拉伸模板。模板按内容版本识别；同一张图已有旧版标准块时，新插入使用新版拉伸定义，旧实例保留原内容和尺寸。旧定义归档为带“旧版”后缀的内部块名，图框库仍按标准名称识别，避免重复适配；取消插入不切换版本。已插入的旧图框不会自动改变拉伸关系，需要使用新插入的图框替换。
本次仅重新打包A0/A1/A2三个加密资源，其他目录及封面模板保留。

从v26升级到v27：更新对应平台的Runtime.dll后执行ZBP_RELOAD即可。新版模板仍加密内嵌，不需要复制目录中的原始DWG。

## v28 界面调整
属性图框顶部：读取样板图框、框选写入图框、应用当前全图、全选字段、取消全选 | 一键图名、图框编号。竖线后的两个按钮独立编组。图框编号由图框签名的其他分组移至此处，编号逻辑保持不变，仍通过原生命令上下文框选图框。
CAD 下拉菜单标题改为出图中心；刷新菜单时移除原 XJG批量打印 菜单。自动加载生成的菜单文件也使用新标题。
从v27更新：替换对应平台Runtime.dll并执行ZBP_RELOAD。
