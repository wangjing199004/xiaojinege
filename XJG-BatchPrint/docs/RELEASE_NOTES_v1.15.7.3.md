# 批量打印插件 v1.15.7.3 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。多文件批打增加模型/布局勾选，并改进通用型扫描反馈与打印后清理。

## 多文件批打

- 扫描多文件时弹出模型/布局勾选对话框，可按空间选择要扫描的范围。
- 修复接入多文件空间勾选后，通用型表单中文编码损坏的问题。

## 通用型批打

- 扫描失败时展示完整异常信息，便于反馈定位（例如 eNotApplicable）。
- 保留完整异常展示，并与多文件空间勾选合并。

## 界面与清理

- 打印结束（成功/取消/异常）后清理临时红框与序号，避免中望偶发残留。
- 序号改为单个宋体文字绘制。

- LA批打印-AutoCAD2015-2024-v1.15.7.3.zip
- LA批打印-AutoCAD2025-2027-v1.15.7.3.zip
