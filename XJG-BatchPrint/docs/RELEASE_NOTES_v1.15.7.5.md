# 批量打印插件 v1.15.7.5 发布说明

本版本覆盖 ZWCAD、AutoCAD 2015–2024 和 AutoCAD 2025–2027。相对 **v1.15.7.4** 的更新如下。

## 相对 v1.15.7.4 的更新

### 图框库

- 新增图框时可「套用已有图框」：按当前纸张尺寸筛选库内条目，一键套用字段相对坐标。
- 字段框选对话框改为非模态，可对照红色临时框缩放/平移后再确认。
- 抽取统一的字段相对坐标换算（`TitleBlockRegionConverter`）。

### 设置

- 修复「转图分辨率(DPI)」输入会被立刻夹回 600 的问题：失焦或回车后再规范到 72–600。

### 多文件批打

- 可按源文件分别选择打印样式（CTB），不再整批共用一个。
- 多文件批打不再绘制序号红框（减少干扰与残留）。

### 输出与合并

- 合并 PDF 时可选择保留单张 PDF。
- 「完成后打开输出文件夹」覆盖各输出格式（含 DWG）；澄清未勾选合并时该选项的文案。

### 扫描与清单

- 框选/范围扫描结果改为累加到现有清单；通用型提供清空清单。
- 扫描范围窗改为四个按钮直选（不再绕一层确认）。

### DWG 拆图

- 带 XCLIP 的块参照按裁剪框判断去留（相交或被包含即保留），避免裁剪块被误删。
- 复制/移动后用当前块变换校正裁剪坐标；读不到边界时保守保留。
