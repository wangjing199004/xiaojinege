# XJG 批量打印插件 — 交接说明

> 最后更新：2026-10-14

## 一、这是什么

一个 AutoCAD 批量打印插件（原名 batchPrintZWCAD / LA批量打印，现更名 **XJG批量打印**，由 XJG 基于 LA批量打印源码修改），支持图框块批量打印、矩形框通用批量、图框库管理、单张打印、多种输出格式（PDF/PNG/JPG/DWF/DWG）。

- 目标版本：AutoCAD 2015~2024（.NET Framework 4.8，x64）
- 编译引用：NuGet `AutoCAD.NET` **20.0.1**（AutoCAD 2015 / R20.0 SDK）。**必须引用最低支持版本**才能覆盖 2015~2024。
  （中途曾改为 AutoCAD 2024 本地引用 R24.3 / 24.3.171.0.0，已回退——高版本引用会让 2015~2023 无法 `NETLOAD`。详见第七节。）

## 四、怎么编译

```bash
cd LABatchPlot
dotnet build src/AcadBatchPlot/AcadBatchPlot.csproj -c Release
```

- 产物输出到 `bin-acad\`
- 首次编译会联网还原 NuGet 依赖（Newtonsoft.Json、PDFsharp、SharpZipLib、Docnet.Core 等）
- 需要 .NET SDK 8.x（环境已验证 8.0.420 可用）

## 五、怎么加载使用

1. 打开 AutoCAD 2024 → 命令行 `NETLOAD`
2. 选 `bin-acad\AcadBatchPlot.dll`
3. 首次打开主面板会自动安装 LA_pdf/png/jpg/dwf 绘图仪（等几秒）

**主命令**：

| 命令 | 作用 |
|---|---|
| `ZBP_SHOW_PANEL` | 打开主面板（5 Tab：图框块打印 / 通用批量 / 单张打印 / 图框库 / 设置）|
| `ZBP_RECTANGLE_BATCH_PLOT` | 打开主面板并切到「通用批量」Tab |
| `ZBP_SINGLE_PLOT` | 打开主面板并切到「单张打印」Tab |
| `ZBP_MANAGE_LIBRARY` | 打开主面板并切到「图框库」Tab |
| `ZBP_SETTINGS` | 打开主面板并切到「设置」Tab |
| `ZBP_SHORTCUT_SETTINGS` | 打开「设置」Tab 并选中内部「快捷键」二级标签 |
| `ZBP_ADD_TITLE_BLOCK` | 新增图框到图框库（命令仍可用，菜单已移除）|
| `ZBP_INSTALL_AUTOLOAD` | 装自动加载（以后不用 NETLOAD）|

**菜单栏**（`CadMenuInstaller` 安装，菜单名「XJG批量打印」）：图框块打印 / 通用型批量打印 / 单张打印 / 图框库管理 / 安装自动加载 / 卸载自动加载 / 关于。

用户数据在 `%APPDATA%\AcadBatchPlot`（图框库/设置/日志）。

## 六、关键改动记录

### 0. 引用回退（AutoCAD 2024 → 2015）
- `src/AcadBatchPlot/AcadBatchPlot.csproj`：删除 `DLL2024\` 的三个本地 `Reference`（acmgd / acdbmgd / accoremgd，24.3），
  改为 `<PackageReference Include="AutoCAD.NET" Version="20.0.1">` + `PrivateAssets=all` + `ExcludeAssets=runtime`。
- 包级联：`AutoCAD.NET`(AcMgd) → `AutoCAD.NET.Core`(AcCoreMgd) → `AutoCAD.NET.Model`(AcDbMgd)，20.0.1 均在本机 NuGet 缓存，**可离线还原**。
- 结果：**0 个编译错误**，说明代码未使用任何 2021+ 新增 API。产物引用版本由 24.3.0.0 变为 20.0.0.0。
- 编译写入 `bin-acad\` 时被运行中的 AutoCAD 锁定，故本次产物先输出到 `bin-acad-2015\`。

### 0.5 剩余 2 个 WinForms 窗体迁移到 WPF
- `CustomScaleForm.cs` → `CustomScaleForm.xaml` + `.xaml.cs`（模态，`CadDialog.ShowModal`）；
  结果由 `DialogResult=OK` 改为 `DialogResult=true`。
- `FieldBoxSelectDialog.cs` → `FieldBoxSelectDialog.xaml` + `.xaml.cs`（**非模态**，Topmost）。
- 三个 WinForms→WPF 必踩的坑：
  1. **WPF `Window` 不实现 `IDisposable`**，所有 `using var form = new XxxForm()` 必须改成普通变量（否则 CS1674）。
  2. **非模态 WPF 窗口不能设置 `Window.DialogResult`**（抛 `InvalidOperationException`）。故 `FieldBoxSelectDialog` 
     改用自定义 `public bool Accepted`；确认/跳过置 true，取消保持 false。
  3. **非模态窗口不能用 `IsCancel="True"`**（它内部会去设 `DialogResult` 同样抛异常）。取消按钮改为显式 `Click` 关闭，
     Esc 键用 `PreviewKeyDown` 自己接管。
- 调用方同步改造：`ArbitraryPaperPicker.DetectCandidatesOrPrompt` 的 `owner` 由 `Form?` 改 `Window?`；
  `ShowScaleDialog` 返回 `bool?`；`BatchPlotCommands.ShowModelessDialogAndWait` 改为 WPF 版。
- **等待非模态关闭必须用 `Dispatcher.PushFrame`**：只用 WinForms 的 `Application.DoEvents()` 不驱动 WPF 的
  Dispatcher，窗口点击/布局/重绘会得不到处理（表现为按钮点了没反应）。

### 0.6 图框库 → 批量打印联动（LibraryChanged）
- `MainWindow` 保存 `_batch` / `_library` 两个面板引用，订阅 `_tabs.SelectionChanged`。
- 切回「批量打印」Tab 且 `TitleBlockLibraryControl.LibraryChanged` 为真时：
  调 `BatchPlotControl.RefreshAfterLibraryChange()` → 清除标记。
- `BatchPlotControl` 新增 `_lastScanScope` / `_lastSelectedIds` 记住上次扫描条件，抽出 `RunScan(library, scope, ids)`；
  变更后**静默重扫**（不再弹扫描范围/对象选择对话框），整体替换清单。
- 保护：清单为空（从未扫描）、无可复用扫描条件、图框库被清空 → 不动作；重扫异常只写日志，不动原清单。
- ⚠ 已知代价：重扫是整体替换，用户在清单里手工改过的图名/图号会被重新识别结果覆盖。

## 七、注意事项

- **⚠ 引用策略（最高优先级，改前必读）**：`AcadBatchPlot` 要覆盖 **AutoCAD 2015~2024**，就必须引用**最低支持版本** SDK 编译——即 NuGet 包 `AutoCAD.NET` **20.0.1**（AutoCAD 2015 / R20.0）。跨版本兼容的方向是单向的：低版本编出来的插件能在高版本宿主跑，反过来不行。引用 24.3 编译出的 DLL 在 2015~2023 上 `NETLOAD` 会因托管程序集版本不匹配而失败。
  - 已验证：新 DLL 引用的 `acmgd / acdbmgd / accoremgd` 版本为 **20.0.0.0**（旧版为 24.3.0.0）。
  - `ExcludeAssets="runtime"` 必须保留：保证这三个 DLL 不被复制进插件目录，始终用宿主自带的。
  - 如需临时做 2024 专用构建，再回退到 `DLL2024\` 本地 `Reference`，但**同一份产物不能同时兼顾**。
- **打印引擎**：托管 PlotEngine（矢量），不是栅格；LA_pdf.pc3 本质是 DWG To PDF 的复制品。只有 PNG/JPG 走栅格（临时 PDF 转图）。
- **前台打印**：`BACKGROUNDPLOT=0`（保证文件写完）。
- **单张打印/设置已整合进主面板 Tab**（v1.15.9 后续）：它们的 CAD 框选/点选交互统一改为「隐藏主面板 → 回 CAD 交互 → 恢复」，
  复用 `CadWindowFocus.HideForCadInput/RestoreDialog`（与通用批量「框选扫描」同一套路）。设置 Tab 用「保存」按钮显式提交，
  并通过 `SettingsChanged` 标记让批量打印/通用批量 Tab 切回时自动刷新。
- 换电脑后第一次编译需要联网还原 NuGet。
