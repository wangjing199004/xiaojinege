# 标准图框宿主回归

HostRegression.cs 为 AutoCAD 控制台命令 STD_TEST。使用 .NET Framework csc 引用 AutoCAD2024 的 AcCoreMgd、AcDbMgd、AcMgd 编译，NETLOAD后执行。
XJG_HP_TEST_ROOT 可指定工作区；读取 bin-update-v23/AutoCAD2015-2024/AcadBatchPlot.dll。
逐个从DLL内置加密资源插入7个标准图框，在独立数据库检验：属性/默认值为空；所有可达嵌套图块、动态基础/匿名图块、属性均0层；根参照使用当前图层，几何中心对齐指定点且定义原点不变；原有图层锁恢复；距离1默认为允许最小值、其他动态参数和切换保留；重复插入复用同一有效块定义，第二实例仍采用默认动态尺寸；原始模板字节不变；原生Jig.Update连续移动；预览参照位于不可见临时容器、确认前当前空间实体数不增加；取消后的实体/定义数量、图层锁回归。
测试DWG及日志写 local-artifacts/hp-template-inspect，不修改用户图纸。
未覆盖真实按钮点击和鼠标取点，其他CAD平台需宿主验证。

空白目录交互验收：标准图框面板仅显示5项；清空扫描列表后点击生成HP目录，默认预览A4；连续右键、空格、S切换A3/A4，预览中心保持不变；单击仅保留最终目录，Esc不残留目录或临时定义；结束后右键菜单设置恢复。有扫描内容但未勾选时仍提示勾选，不走空白目录。真实键鼠交互需在CAD窗口验收。
