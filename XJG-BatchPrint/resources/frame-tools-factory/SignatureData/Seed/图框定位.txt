# A1 图框签字 · 图幅定位（「图幅标定」生成，也可以直接用记事本改）
# 每行一个图幅：A0/A1/A2/A3@RB=内容高,姓名列左上角dx,dy,签名列右下角dx,dy（相对该图框内容右下角的偏移，块内坐标）
# 「图框签名」框选时按内容高度匹配图幅（±5%）；签字栏跟右缘走时，拉伸/平移/缩放/旋转都能对准。删除对应行即作废该图幅标定。
# 本机还没有标定任何图幅：打开面板 → 点「图框签字」右边的「>」→ 对 A0/A1/A2/A3 各标一次 → 点「确认」写入本文件。
